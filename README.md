# fernandorojasstudio.com — static site

Personal portfolio for Fernando Rojas. Single static `index.html` plus
`assets/`, hash-routed (`#/` routes), served by Vercel with the SPA rewrite
in `vercel.json` (`/(.*)` -> `/index.html`). Contact form posts to Formspree.

Previous version was a Create React App. Its source is archived at
`workspace/goals/personal-website-homepage-redesign/hidden_files/live-archive-2026-11-11-pre-v42/`
(repo at commit `4c8dfb71`); to roll back, redeploy that commit.
